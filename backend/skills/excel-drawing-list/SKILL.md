# Drawing List

先用名称、材质工艺、尺寸、数量、单位列建立项目目录，再核对每张图纸的锚点和实际内容。锚点只是归属线索；图纸内容明显不对应所在行时记录疑问，不强行套用。

从表格保留材质工艺原文、颜色、灯光、单双面与备注；从明确图纸标注提取成品尺寸、单字尺寸、文字组成和部件。材料板厚与整体壳深分别处理。

字类的成品数量是套数，character_count 和 letter_groups.count 是每套字数。不同字高、宽度或语言组分开。单字计价长度需要明确依据，不用整行长度替代。分组宽高缺失时不把整套外接尺寸复制给所有字。

本批的每个图纸关联项目都返回一行，即使尺寸读不清。不能因为分批而询问“后续批次是否还有这些图纸”或将已在其他批次的图纸算成缺失。完成本页后统一核对实际目录覆盖。
