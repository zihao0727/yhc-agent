# Freeform Workbook

按实际布局识别字段和值的对应关系，而不是假定每一行都是一个产品。竖向属性表、横向产品矩阵、多区块、分节页各自定位。

只在项目关系明确时组合多个单元格。合并区域左上角的值不意味着覆盖所有可见行；父标题也不一定是产品名称。保留真实地址、区块关系、原文与缺失项。

数量和尺寸不能靠相邻数字猜测。若结构超出现有解析方法，规划阶段选择创建专门 skill；生成的内容只描述可复用的结构方法，不含客户名称、实际金额、密钥、文件路径或原始业务数据。
