# Price Reference

先区分产品、材料、厚度、规格、表面处理、适用语言、单价及计价单位。横向矩阵按行列共同约束理解，不能只读取某一列标题。

此输入是参考价格，不代表客户订购数量。最小起订量、计价档位、最低面积与损耗条件不能填为成品 quantity。历史或参考金额不能写进需求 schema，也不能自动启用或修改报价库价格。

只在存在明确客户项目及订购事实时整理为制作需求。只有价目表时可返回空 lines，并说明需要客户制作清单；保留该文件作为来源。不要为了生成报价而虚构每种材料各买一件。
