# Quantity List

识别实际表头位置及名称、规格、数量、单位、工艺和备注的语义。表头不一定在第一行，列名也不固定；按当前工作簿证据映射，不照抄其他模板地址。

保留分节、父子项目和合并单元格关系。只有明确共享说明才适用到子行，不能把上一行材质、尺寸或数量自动向下填充。不同规格独立保留。

个、件、套等成品数量可用于 quantity；长度、面积、重量和材料用量保留原值与单位，不强行改成件数。实际数量空白与零不等价。公式无可靠缓存时不计算或补猜。

纯材料清单不能冒充成品制作要求；缺少产品用途或制作做法时明确记录。小计、合计、税额等汇总不重复计数。
